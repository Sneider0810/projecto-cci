# Registro de uso de IA

**Herramienta:** Claude Code (modelo Claude Opus 5.5, de Anthropic), usado desde la aplicación de escritorio.

La herramienta se utilizó como apoyo técnico durante la elaboración del proyecto. Su uso se limitó a la corrección de errores, revisión de sintaxis, depuración y complementación de fragmentos de código, así como a ajustes de implementación, formato y visualización.

| Parte | Uso de Claude Code | Verificado por el grupo |
|---|---|---|
| General | Apoyo técnico para organizar la estructura del notebook, revisar la sintaxis y complementar fragmentos de código. | |
| A1 | Corrección de sintaxis, ajuste de instrucciones de código y apoyo en la depuración de la implementación. | |
| A2 | Ajustes de código para ejecutar los procedimientos programados y corrección de errores de implementación. | |
| A3 | Corrección de código para generar la tabla y la figura, y ajustes de formato de visualización. | |
| B1 | Corrección de sintaxis y depuración del código relacionado con los cálculos, las validaciones y la generación de la figura. | |
| B2 | Complementación y corrección de fragmentos de código para construir los bloques y ejecutar las instrucciones programadas. | |
